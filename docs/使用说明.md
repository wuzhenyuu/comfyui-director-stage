# 🎬 3D导演台 · 使用说明

> 面向使用者的完整操作手册。节点接线与输出通道说明见 [README.md](../README.md)。

---

## 1. 打开导演台

1. ComfyUI 画布中添加节点：`🎬DirectorStage → 🎬 3D导演台`
2. 点击节点上的「🎬 打开导演台」
3. 编辑完成后点右上「✅ 应用到节点」，控制图自动渲染上传并写回节点

场景数据随 workflow 保存，重新打开工作流后可继续编辑。

---

## 2. 界面总览

- **左侧「角色」页**：3D角色列表、骨骼显示开关、动作栏、姿态预设、行走路线
- **左侧「机位」页**：多机位管理、焦距、构图安全框
- **左侧「道具」页**：添加/管理场景道具
- **左侧「属性」页**：选中对象的参数
- **顶栏**：添加角色、撤销/重做、复制粘贴、骨骼显示、全景、导入 OpenPose、导入/导出工程、MP4 参考视频、应用到节点
- **中央视口**：3D 场景，鼠标拖动旋转视角、滚轮缩放

---

## 3. 角色管理

### 添加角色

- 顶栏或角色面板的「➕」→ 从模型库选择（内置 Michelle / X Bot / UE 人体 / Alicia VRM 等）或导入本地 GLB / VRM 文件
- 最多 **8 个**角色，新角色自动错位出生并激活

### 角色列表（每行四个操作）

| 操作 | 说明 |
|---|---|
| 点击行 | 激活该角色（动作/姿势操作都作用于活动角色） |
| 👁 | 隐藏 / 显示 |
| ✏️ | 重命名 |
| 🗑️ | 删除（有确认弹窗） |

> 列表区域超过约 5 行时内部滚动。

---

## 4. 三种操作模式（重要）

同一个角色、同一套骨骼数据，三种操作方式：

### 🧍 整体移动（角色模式）
- 点住角色身体拖动 = 地面平移；**Alt + 拖动 = 升降**
- 视口操纵器（gizmo）：**W** 移动 / **E** 旋转 / **R** 缩放（快捷键在掌镜中、输入框聚焦、骨骼模式下不生效）
- 缩放范围 0.2~3.0 等比

### 🎯 IK 模式（默认，快速摆姿势）
- 拖手/脚的 **IK 球**，系统自动计算手臂、腿部弯曲
- 适合快速摆站姿、坐姿、挥手等大姿势

### 🦴 骨骼模式（精细调整）
- 勾选「显示骨骼」后，点「🦴 骨骼」进入
- 点击骨骼标记点选中骨骼 → 出现 3D Gizmo
- 默认三维**旋转**；骨盆/Root 支持 **XYZ 平移**；勾选「高级」后开放更多骨骼平移（⚠️ 可能导致模型拉伸变形）
- 支持局部坐标 / 世界坐标切换

### 模式切换规则（不会乱的关键）

> **骨骼模式里骨骼是主人，IK 模式里 IK 球是主人，切换时自动同步一次。**

- 切到骨骼模式：以当前骨骼姿势为准，IK 球自动隐藏
- 切回 IK 模式：IK 球自动对齐到当前手脚骨骼位置，姿势不跳变
- **骨骼模式下点动作预设 / 播放行走路线 → 自动切回 IK 模式再执行**（动作和行走基于 IK 驱动；模型自带动画 clip 直接驱动骨骼，不受影响）
- 路线播放中切到骨骼模式：角色位置原地冻结（不会滑步），切回 IK 自动续走

## 5. 动作预设与模型动画

- **动作预设**（程序化）：站立 / 坐下 / 蹲下 / 躺下 / 出拳 / 待机 / 走路 / 跑步 / 挥手 / 跳跃
  - 点快捷按钮即播即切；下拉框 + ▶ 播放/暂停；⏹ 停止全部回站立
  - **速度**（0.1~3×）、**强度**（0~2）滑块实时生效
- **模型动画**：模型自带的 AnimationClip（如下拉框「模型动画」分组），由骨骼关键帧直接驱动
- 跳跃等一次性动作播完自动回站立

---

## 6. 姿态预设（自定义姿势库）

1. 摆好姿势（IK / 骨骼模式均可）
2. 「姿态预设」区输入名称（可留空自动编号）→ 点「💾 保存姿态」
3. 点预设名 = 应用；支持重命名 / 删除
4. 预设保存的是**骨骼数据**（旋转 + 允许的位移），不保存角色位置、相机、道具
5. 随工程一起保存（sceneJSON），刷新/重开可恢复复用
6. 骨架不同的角色应用时按骨骼名部分匹配，并有提示

---

## 7. 行走路线

1. 「行走路线」区点「➕ 创建行走路线」，在视口点选路径点
2. ▶ 播放 / ⏸ 暂停 / ⏹ 停止；角色沿路径行走并自动播 walk 动作（优先模型自带 walk 动画，否则程序化走路）
3. **跟随相机轨迹**：勾选 follow 后，相机轨迹播放时人物按同一进度走，轨迹停人物停
4. 路线点支持 3D gizmo 拖动编辑、删除单点
5. 到终点自动停住回站立（loop=false）

---

## 8. 机位系统

- **多机位**：机位页可添加多个机位，**Ctrl + 1~9** 快速切换
- **焦距**：35mm 等效焦距调节；三分/中心构图安全框
- 每个机位独立导出控制图（配合 `DirectorStageShot` 节点多机位分镜，见 README）

---

## 9. WASD 掌镜（第一人称运镜）

- 激活掌镜后：**W/S** 前进后退，**A/D** 左右平移，**Q/E** 升降
- **空格**：播放 / 暂停全部角色动作
- 掌镜状态可随相机轨迹录制，形成运镜路径

---

## 10. 相机轨迹与多帧导出

- 机位页创建相机轨迹（多个轨迹点 + 时长），时间轴播放预览
- 沿轨迹**逐帧导出**控制图：manifest 的 `files` 写成帧数组，后端堆叠为 batch，可直接接视频工作流
- 导出帧数、机位粒度独立，单帧行为不变

---

## 11. 道具

- 道具页添加桌椅、方块等基础道具，拖放摆位，支持旋转/缩放
- 道具随场景一起保存/导出

## 12. 编辑操作

| 快捷键 | 功能 |
|---|---|
| Ctrl + Z | 撤销 |
| Ctrl + Y | 重做 |
| Ctrl + C / V | 复制 / 粘贴选中对象 |
| Ctrl + 1~9 | 切换机位 |
| W / E / R | 角色 gizmo：移动 / 旋转 / 缩放 |
| Alt + 拖身体 | 角色升降 |
| 空格（掌镜中） | 动作播放/暂停 |

## 13. 导出与出图

- 「✅ 应用到节点」：渲染并上传 6 通道控制图（openpose / depth / normal / lineart / char_masks / camera_json）
- **MP4 参考视频**：把场景动作录成参考视频，供视频工作流参考
- 控制图强度建议：openpose 0.9~1.0，depth 0.4~0.7

## 14. 常见问题

**Q：骨骼模式下动作预设/姿势变了样？**
A：已修复（2026-07 版起）：骨骼模式点动作预设会自动切回 IK 模式。模型动画 clip 不受影响。

**Q：骨骼编辑后切回 IK，姿势跳了？**
A：不会。切回时 IK 球按当前骨骼位置重新对齐，姿势无缝接管。

**Q：角色行找不到删除按钮？**
A：角色列表现在固定显示每行的 👁/✏️/🗑️，列表超高时内部滚动。

**Q：播放行走路线角色不动？**
A：骨骼模式下路线推进是冻结的；点播放会自动切回 IK 模式。

**Q：场景能保存吗？**
A：自动随 workflow 保存；也可用顶栏「导出工程」存为独立文件，跨工作流复用。
